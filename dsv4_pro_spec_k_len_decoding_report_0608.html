4. 結論與建議

  • 吞吐/延遲均速：k=3 全贏 — TPOT 78.5 vs 121.17（−35%）、throughput 19.13 vs 13.83（+38%）、duration −28%；acceptance length 漲到 3.66。
  • 正確性：lossless — 三組 0.953–0.957，差異在雜訊內，皆 > 0.9（全量門檻）。
⚠️ Tradeoff：k 越大 P99 ITL 急遽惡化（352 → 2951 → 3437 ms），TTFT、acceptance rate 也略差。
• 離線 / 批次 / 拼吞吐 → 選 k=3（可再試 k=4）。
• 互動 / 有 P99 latency SLA → P99 尾延遲是風險，需用大量 request 重測 P99 確認非雜訊（本次僅 2 prompts，尾延遲樣本不可靠）。
